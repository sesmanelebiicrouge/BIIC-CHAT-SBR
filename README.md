# BIIC-CHAT-SBR

BIIC CHAT — SBR est une application de messagerie et de communication qui permet aux utilisateurs d’échanger des messages et de participer à des discussions de groupe.

## Stack
- Flutter / Dart
- Material Design
- Structure de projet orientée application de chat

## Structure du projet
- `lib/main.dart` : point d’entrée et écran de chat
- `pubspec.yaml` : dépendances et configuration du projet

## Prérequis
- Flutter SDK installé
- Android Studio / VS Code / Xcode selon le type de build voulu

## Installation
1. Ouvrir le dépôt localement
2. Exécuter :
   ```bash
   flutter pub get
   ```
3. Lancer l’application :
   ```bash
   flutter run
   ```
