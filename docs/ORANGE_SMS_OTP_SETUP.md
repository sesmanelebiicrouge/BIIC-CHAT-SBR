# BIIC CHAT — Orange Côte d'Ivoire SMS OTP

BIIC CHAT keeps Supabase Auth responsible for generating and validating the OTP. The Supabase **Send SMS Hook** replaces the built-in SMS delivery and sends the generated 6-digit code through Orange Côte d'Ivoire.

## Files

- `supabase/functions/send-sms/index.ts` — secure Orange SMS hook.
- `supabase/functions/.env.example` — secret names only.
- `lib/services/auth_service.dart` — remains the client-side Supabase Auth layer.

## Required production secrets

Set these in **Supabase → Edge Functions → Secrets**. Do not put them in Flutter, GitHub, `.env` committed files, or the web bundle.

- `ORANGE_SMS_CLIENT_ID`
- `ORANGE_SMS_CLIENT_SECRET`
- `ORANGE_SMS_SENDER` (keep `tel:+2250000` for Côte d'Ivoire)
- `ORANGE_SMS_SENDER_NAME` (set only after Orange approves the sender name, e.g. `BIICCHAT`)
- `SEND_SMS_HOOK_SECRET`

Supabase documents Edge Function secrets as the correct place for third-party API credentials. 

## Orange prerequisites

1. Create an application in Orange Developer.
2. Subscribe the application to the Côte d'Ivoire SMS API.
3. Purchase an SMS bundle.
4. Obtain the Orange Client ID and Client Secret.
5. Request/validate the sender name if Orange requires a custom sender.

For Côte d'Ivoire, do not add the `SMS_OCB2` query parameter: Orange documents that parameter for Orange-only/on-net traffic. The general Côte d'Ivoire SMS API uses the normal `/outbound/tel%3A%2B2250000/requests` endpoint.

Orange's current API uses OAuth 2.0. The access token lasts about one hour; the function requests a token when needed. 

## Supabase Auth Hook

In Supabase Dashboard:

1. Authentication → Hooks.
2. Create/enable **Send SMS**.
3. Choose HTTPS / Edge Function.
4. Select the deployed `send-sms` function.
5. Generate the webhook signing secret.
6. Put the same secret in `SEND_SMS_HOOK_SECRET`.
7. Keep phone confirmation enabled so Supabase still validates the OTP.

The hook receives the user phone number and the OTP generated by Supabase Auth. A successful HTTP 200 response tells Supabase that delivery succeeded. The signing secret may be stored in the standard `v1,whsec_...` format; the function normalizes it before verification.

## Security

The Orange Client Secret never leaves the Edge Function. The Flutter application continues to call:

`signUp(... channel: OtpChannel.sms)`

and:

`verifyOTP(type: OtpType.signup, ...)`

The OTP itself is generated and checked by Supabase Auth; Orange is only the delivery channel.
